# HC working set 索引

這是獨立整理的 76 項 working set；名稱、分類與中文釋義是本專案的工作版本，並非 Minerva 官方完整或最新清單。已核對的範圍與未確認項目見 [來源紀錄](../sources/provenance.md)。其中 20 項在三章展開為 24 則情境條目，其餘僅供按需查找；數量不代表品質。
